# Lesson 1: What is a Network

- **Network** a connection between 2 or more computers

- **LAN** *Local Area Network*

    - A LAN connects computers and devices within a confined space.
 
    - Benefits: Quick communication, reliable and fast transmission, resource sharing, data storage security
 
- **NIC** *Network Interface Card*

    - Works as the ear & mouth of the computer to communicate

- **WAN** *Wide Area Network*

    - Connects multiple local networks across a large geographical area
    - WAN performance can vary depending on factors such as type of tech you use and the physcial distance between network endpoins.
 
- **MAC Address** *Metropolitan Area Network*

    - Can span an entire city or town
    - Uses IEEE 802.11 networking standards for better perforance and increased bandwith
    - fiber is commonly used
 
  - **PAN** *Personal Area Network*
 
      - portability, affordability, reliability, security is top
   
  - **CDN** *Content Delivery Network*
 
        - A network of distributed servers strategically placed in various locations around the world.
 
        - Designed to enhance the delivery of web content to end users
 
        - offers reduced latency by serving content from servers that are closer to the end users. minimizes the time it takes for data to travel from the server tot he user's device
         - often include security features to protect the websites and their users from various threats, such as distrubted denial of service attacks and traffic spikes.
 
- **VPN** *Virtual Private Network*

      - enables users to establish a secure, encrypted connection over the internet

      - enhance privacy by encrypting internet traffic, making it difficult for third parties, including ISPs and hackers, to monitor or intercept a user's online activities.

      - allows users to mask their real location and appear as if they're accessing the internet from a different geographical location. Also known as *Geo-spoofing*
  
- **Geo-Spoofing** is useful for accessing region restricted content or bypassing internet censorship, and security.

- **SAN** *Storage Area Network*

      - a specialized high-speed network that provides access to storage devices

   Which network component is responsible for managing the wireless connection?

   - Access point  *Access points manage wireless connections by providing connectivity between wireles devices and the wired network.*

2. A university campus has multiple buildings connected by underground fiber-optic cables.

   Which network component manages the flow of data between these buildings?

   - Router *Routers direct data between different networks, such as those in separate buildings, by determining the best path for transmission.*
